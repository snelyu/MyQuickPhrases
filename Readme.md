📋 My Quick Phrases (v1.3.0)
자주 사용하는 문구와 템플릿을 저장하고, 클릭 한 번으로 간편하게 복사하는 생산성 도구입니다.

🌟 주요 기능 (Key Features)
다국어 지원 (KO/EN): 헤더의 KO / EN 버튼을 통해 한국어와 영어 인터페이스를 즉시 전환할 수 있습니다.  

항상 위 (Always on Top): 📌 항상 위 체크박스를 활성화하면 다른 창을 클릭해도 프로그램이 가려지지 않습니다.  

지능형 드래그 앤 드롭 (1.5s Long-Press):

문구 카드를 1.5초 동안 길게 클릭하면 이동 모드가 활성화됩니다.  

실수로 순서가 바뀌는 것을 방지하며, 활성화 시 카드의 색상이 변경됩니다.

실시간 순서 변경 (Real-time Swap): 드래그하는 동안 문구들의 위치가 실시간으로 스왑되어 직관적인 정렬이 가능합니다.  

주석 및 힌트 기능: 각 문구마다 본문 외에 짧은 설명(주석)을 달 수 있어, 어떤 문구인지 한눈에 파악하기 쉽습니다.  

데이터 관리 (Import/Export):

💾 저장: 현재 리스트를 .json 파일로 내보낼 수 있습니다.  

📂 불러오기: 저장된 .json 파일을 다시 불러와 리스트를 복구할 수 있습니다.  

자동 업데이트 확인: 프로그램 시작 시 GitHub 서버의 version.json을 확인하여 최신 버전이 있을 경우 업데이트 안내 창을 띄웁니다.  

🚀 사용 방법 (Usage)
문구 추가: + 문장 추가 버튼을 눌러 주석과 본문을 입력합니다.  

복사: 리스트의 문구 카드를 짧게 클릭하면 즉시 클립보드에 복사됩니다.  

수정/삭제: 카드 우측 하단의 ✎(수정) 버튼이나 ✕(삭제) 버튼을 사용합니다.  

순서 변경: 카드를 1.5초간 누른 뒤 원하는 위치로 끌어다 놓습니다.  

🛠 설치 및 실행 (Installation)
Python이 설치되어 있어야 합니다.

필수 라이브러리를 설치합니다:

Bash
pip install pyperclip requests
프로그램을 실행합니다:

Bash
python copy_tool.py

📄 README_EN.md (English Version)
📋 My Quick Phrases (v1.3.0)
A productivity tool to save and manage your frequently used phrases with one-click copy functionality.

🌟 Key Features
Multi-language Support (KO/EN): Instantly toggle between Korean and English interfaces using the KO / EN button in the header.  

Always on Top: Enable the 📌 Always on Top checkbox to keep the application visible above all other windows.  

Intelligent Drag & Drop (1.5s Long-Press):

Long-press for 1.5 seconds to activate move mode.  

This prevents accidental reordering; the card color changes to indicate it's ready to move.

Real-time Swap: Phrases swap positions in real-time as you drag, allowing for intuitive organization.  

Notes & Hints: Add brief descriptions (notes) to each phrase to easily identify them.  

Data Management (Import/Export):

💾 Export: Export your current list to a .json file for backup.  

📂 Import: Restore your list by importing a previously saved .json file.  

Auto-update Check: Upon startup, the app checks version.json on the GitHub server and alerts you if a newer version is available.  

🚀 How to Use
Add Phrase: Click the + Add Phrase button to enter a note and the main content.  

Copy: Briefly click a phrase card to copy the content to your clipboard instantly.  

Edit/Delete: Use the ✎ (Edit) or ✕ (Delete) buttons located at the bottom right of each card.  

Reorder: Press and hold a card for 1.5 seconds, then drag it to your desired position.  

🛠 Installation & Execution
Ensure Python is installed on your system.

Install the required libraries:

Bash
pip install pyperclip requests
Run the application:

Bash
python copy_tool.py
